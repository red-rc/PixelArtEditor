# Pixeller

**A pixel-focused image editor for game textures and technical graphics.**

Pixeller is built for precise raster editing, where individual pixels and image properties matter more than photo retouching or complex color grading.

## Features

Pixeller is under active development. Current tools include:

- **Pencil** — draw individual pixels.
- **Eraser** — remove pixels.
- **Color Picker** — sample colors from the canvas.
- **Fill Tool** — fill enclosed areas.
- **Hand** — navigate the canvas.

## Supported Formats

PNG, JPEG, BMP, GIF, TIFF, SVG, DDS, WebP, AVIF, HEIF, TGA, PBM, QOI, DICOM, PDF, ICO

## Image Properties

Pixeller supports a range of image formats, pixel layouts, and encoding options.

- **Color modes:** RGB, RGBA, BGR, BGRA, ARGB, ABGR, RG, A, L, LA, Indexed, CMYK
- **Bit depths and pixel formats:** 1-bit, 2-bit, 4-bit, 8-bit, 16-bit, RGB565, ARGB1555, RGBA1010102
- **Alpha modes:** None, Straight, Premultiplied
- **TIFF compression:** None, LZW, Deflate, PackBits
- **Color families:** RGB, Grayscale, CMYK
- **Transfer functions:** sRGB, Linear, Gamma 2.2, Gamma 1.8
